Política de privacidad

Esta política explica de forma simple qué información puede recopilar APEX Card Grading y cómo se utiliza dentro de la plataforma.

1. Información que podemos recopilar

APEX puede recopilar datos necesarios para operar la plataforma, como nombre público, email de cuenta, certificados reclamados, cartas agregadas a la colección, códigos ACG, imágenes del análisis y datos técnicos vinculados al servicio.

2. Uso de la información

La información se utiliza para crear cuentas, permitir el acceso a “Mi colección”, reclamar cartas mediante clave privada, mostrar certificados online, administrar registros digitales y mejorar la experiencia del usuario.

3. Colección pública

Cuando el usuario activa o utiliza funciones públicas, como colección pública o dueño registrado, APEX puede mostrar datos visibles como nombre público, username y cartas registradas públicamente. No se muestra el email completo como dato público.

4. Seguridad y claves privadas

Las claves privadas de registro deben mantenerse en reserva. APEX utiliza estas claves para asociar una carta con una cuenta de usuario. Compartir una clave puede permitir que otra persona reclame o solicite transferencia de una carta.

5. Proveedores tecnológicos

APEX utiliza servicios externos para operar la plataforma, incluyendo infraestructura de base de datos, autenticación y almacenamiento de archivos. Estos servicios pueden procesar información necesaria para el funcionamiento técnico de la web.

6. Conservación de datos

Los datos se conservan mientras sean necesarios para mantener los certificados, colecciones, historial operativo y funciones asociadas al servicio, salvo solicitud válida de baja o eliminación cuando corresponda.

7. Solicitudes del usuario

El usuario puede solicitar revisión, modificación o eliminación de datos asociados a su cuenta, sujeto a las necesidades operativas y de trazabilidad de los certificados emitidos.

8. No venta de información

APEX no vende datos personales de usuarios a terceros. La información se utiliza para prestar y mejorar el servicio.

9. Cambios en esta política

APEX podrá actualizar esta política para reflejar cambios en la plataforma, en sus servicios o en requisitos legales aplicables.

10. Contacto

Para consultas sobre privacidad o datos personales, podés contactar a APEX desde los canales publicados en la web.

Este texto es una base informativa inicial y puede ser revisado por un profesional legal antes de su uso definitivo.
